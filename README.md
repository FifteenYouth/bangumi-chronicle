# Bangumi Chronicle · 番组计划外观美化扩展

为 **Bangumi 番组计划**（`bgm.tv` / `bangumi.tv` / `chii.in`）打造的浏览器外观美化扩展，带来清爽柔和的现代视觉体验，让追番点格子、浏览条目与社区交流更加舒适顺手。

---

## ✨ 主要功能

- **全站界面焕新**  
  重新梳理全站页面排版，覆盖首页、番组与书籍/音乐/游戏条目页、章节列表、单集讨论、每日放送日历、排行榜、标签检索、人物与角色页、超展开、小组话题、日志、目录以及个人时光机。

- **浅色 / 深色模式与主题配色**  
  支持清爽浅色、柔和深色以及跟随系统自动切换，夜间逛站不再有刺眼的白底弹窗；内置多款主题强调色，可按个人喜好自由切换。

- **顺手的追番进度管理**  
  在首页集中展示正在追看的番剧与书籍，左侧列表支持一键打卡下一集「看过」，右侧面板可直观查看本篇与 SP 章节进度、批量修改已看话数。

- **高清封面自动替换**  
  自动将页面中的低分辨率模糊小封面替换为清晰大图，让番组海报、角色肖像与放送日历呈现更好的视觉效果。

- **保留原汁原味的评分与使用习惯**  
  完整保留 Bangumi 传统的十星评分展示；点格子、修改收藏、发表吐槽、楼层回复、站内提醒与短信等操作均与原站无缝同步，并支持常用的站内小组件。

- **便捷导航与快捷工具栏**  
  提供清晰的顶部频道导航、分类搜索栏以及可收起的底部悬浮快捷栏，随时快速直达个人时光机、电波提醒、站内短信与外观偏好面板。

---

## 📦 安装方法

1. 前往本仓库右侧的 **[Releases](https://github.com/FifteenYouth/bangumi-chronicle/releases)** 页面，下载最新版本的扩展压缩包（`bangumi-chronicle-v0.1.0.zip`），并将其解压到电脑上的任意文件夹。
2. 在 Chrome 或 Edge 浏览器地址栏输入 `chrome://extensions` 并回车，打开扩展程序管理页面。
3. 打开页面右上角的 **「开发者模式」** 开关。
4. 点击页面左上角的 **「加载已解压的扩展程序」**，选择第 1 步解压出来的文件夹即可完成安装。

---

## 🎨 使用说明

- 安装完成后，直接访问 `bgm.tv`、`bangumi.tv` 或 `chii.in` 即可自动生效。
- 点击网页右上角的日夜切换按钮或 **「外观设定」** 按钮（也可点击浏览器右上角的扩展图标），即可随时切换浅色/深色模式、更换主题色，或临时开启/暂停美化效果。
